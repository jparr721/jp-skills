# Startup stop-doing

Resolve the selected Startup. Record a direct textual rule in `<startupRoot>/standing-instructions.md` with its explicit scope and source, preserving existing instructions. Report the recorded rule and destination.

For a screenshot complaint requiring interpretation or a fix, capture the complete input and image through `jp-startup-intake`. Schedule the investigation or fix as a pipeline or hotfix run. Use the resulting evidence to decide and record a specific enforceable rule. Feedback on dispatched or terminal work becomes a linked follow-up when needed.

Include applicable scoped rules in future assignments. Inform an active run when the new rule affects its work, using its existing input channel. Use the PA only when helpful for questions. For existing legacy teams, route a relevant update through their established assignment and settlement path; preserve their authority and recovery records. A rule does not authorize an unrelated resource mutation.
